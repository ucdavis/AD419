# AD419 Client

React, TypeScript, Vite, TanStack Router, TanStack Query, Tailwind CSS, DaisyUI, and UC Davis Gunrock styles power the AD419 frontend.

## Development

Run these commands from `client/`:

- `npm run dev` starts the Vite development server.
- `npm run build` builds the production assets.
- `npm run lint` runs ESLint.
- `npm test` runs the Vitest suite once.

During normal full-stack development, use `npm start` from the repository root so the backend and frontend run together.
